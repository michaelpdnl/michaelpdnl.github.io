Weather Glass 是一个小实验：为一个朴素的 API 做一个好看的界面。
它从 OpenWeather 获取当前天气，显示在一张随昼夜变化的磨砂玻璃卡片里。

做这个项目学到的东西：

- 如何让 `useEffect` 里的数据请求循环与地点输入保持同步。
- 玻璃拟态需要复杂的背景才好看——渐变不是装饰，而是重点。
- 如何在不到一分钟内把一个 Vite 小应用部署到 GitHub Pages。
